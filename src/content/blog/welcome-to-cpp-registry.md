# Welcome to the C++ Registry

The C++ Registry is a community-maintained registry for C++ libraries, tools and projects.

The goal is simple: make it easier to discover useful C++ projects.

## Why a registry?

There are thousands of C++ projects available across GitHub and other platforms. Finding the right library for a specific task can be difficult.

The registry provides a simple place to discover projects and browse them by language, license, C++ standard and library type.

## Community driven

Projects can be registered by the community.

If you maintain a C++ project, you can add it to the registry through the registration repository.

More updates and improvements to the registry will be posted here.
